# 🎓 Campus Management System

A role-based academic management system designed for colleges, enabling administrators and faculty to manage daily academic operations efficiently.

---

## 🚀 Overview

This system provides a centralized platform for managing notices, timetables, faculty availability, and academic schedules.  
It supports multiple users with secure authentication and role-based access control.

---

## ⚙️ Features

### 👥 Authentication & Roles
- Secure login using JWT  
- Role-based access (Admin / Faculty)

### 📢 Notice Management
- Admin can create and publish notices  
- All users can view notices in real-time  

### 🗓️ Timetable System
- Structured timetable input  
- Displays ongoing classes based on current time  
  *(e.g., 4th Sem - Section A - OOPS)*  

### 📌 Faculty Management
- Mark faculty as absent  
- Absence visible to all users  

### 📝 Personal To-Do
- Individual task tracking for users  

### 📅 Academic Calendar
- Centralized academic event tracking  

---

## 🧱 Tech Stack

- Frontend: React  
- Backend: Node.js  
- Authentication: JWT  
- Database: MongoDB  
- Environment: Linux
